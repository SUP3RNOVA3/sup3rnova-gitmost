# SUP3RNOVA branding overlay

This public AGPL fork tracks Gitmost and applies SUP3RNOVA-owned visual assets to the client shell.

## Upstream baseline

- Gitmost: `v0.94.1`
- Production overlay: `v0.94.1-brand.1`

## Branded surfaces

- Horizontal lockups for light and dark interfaces
- Compact navigation mark for light and dark interfaces
- SVG favicon
- PNG browser and PWA icons
- Browser title and PWA metadata

The application logic and Gitmost attribution remain under AGPL-3.0. Rebase this overlay onto a reviewed upstream release before upgrading production.
